# Minion: ตารางจองรถของครอบครัวบนไลน์

เป็นหน้าเว็บที่เปิดในไลน์ (LIFF) ข้อมูลเก็บใน Google Sheet และตัวหน้าเว็บอยู่บน GitHub Pages ใช้ได้ฟรีทั้งหมด ไม่ต้องมี LINE OA

```
ไลน์ (LIFF)  →  GitHub Pages (index.html)  →  Google Apps Script  →  Google Sheet
```

ใช้เวลาตั้งค่าประมาณ 20–30 นาที ทำตามลำดับนี้

---

## 1. Google Sheet + Apps Script (หลังบ้าน)

1. ไปที่ https://sheets.new สร้าง Sheet ใหม่ ตั้งชื่อว่า **Minion**
2. ไปที่เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิมออก แล้ววางโค้ดทั้งหมดจากไฟล์ `apps-script/Code.gs` จากนั้นกดบันทึก
3. เลือกฟังก์ชัน **setup** ที่ด้านบน แล้วกด **เรียกใช้** (ครั้งแรกจะถามสิทธิ์ ให้กดอนุญาต)
   - จะได้แท็บ `Members` ที่มีชื่อ Big, Game, Yui, Papa และแท็บ `Bookings`
4. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** แล้วตั้งค่าดังนี้
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก **URL ของเว็บแอป** ที่ลงท้ายด้วย `/exec` เก็บไว้ใช้ในขั้นตอนที่ 4

> ถ้าแก้ Code.gs ภายหลัง ต้องไปที่ **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** โค้ดใหม่ถึงจะมีผล

## 2. GitHub Pages (หน้าเว็บ)

1. สร้าง repo ใหม่ชื่อ `minion-line` (ตั้งเป็น Public ได้ เพราะไม่มีรหัสลับอยู่ในไฟล์)
2. อัปโหลดไฟล์ `index.html` และ `config.js`
3. ไปที่ **Settings → Pages → Branch: main / (root) → Save**
4. รอประมาณ 1 นาที จะได้ URL หน้าตาแบบนี้ `https://<ชื่อ GitHub>.github.io/minion-line/`

## 3. LINE Developers (เปิดในไลน์)

1. เข้า https://developers.line.biz/console/ ด้วยบัญชีไลน์ของคุณ
2. สร้าง **Provider** (ตั้งชื่ออะไรก็ได้ เช่น `Family`)
3. กด **Create a new channel → LINE Login**
   - App types: เลือก **Web app**
   - ใส่ชื่อ, คำอธิบาย และอีเมล แล้วกดสร้าง
4. ในแท็บ **Basic settings** คัดลอก **Channel ID** (ตัวเลข) เก็บไว้
5. ไปที่แท็บ **LIFF → Add**
   - Size: **Full**
   - Endpoint URL: URL GitHub Pages จากขั้นตอนที่ 2
   - Scopes: ติ๊ก **openid** และ **profile**
   - กด Add แล้วคัดลอก **LIFF ID** เก็บไว้
6. **สำคัญ:** ที่ด้านบนของ channel ให้เปลี่ยนสถานะจาก **Developing → Published**
   - ถ้ายังเป็น Developing คนอื่นในบ้านจะล็อกอินไม่ได้

## 4. เชื่อมทุกอย่างเข้าด้วยกัน

1. **ใส่ Channel ID ใน Apps Script:** ไปที่ Apps Script → ⚙️ **การตั้งค่าโปรเจ็กต์ → พร็อพเพอร์ตี้ของสคริปต์** → เพิ่มพร็อพเพอร์ตี้
   - ชื่อ: `LINE_CHANNEL_ID`
   - ค่า: Channel ID จากขั้นตอนที่ 3.4
2. **แก้ไฟล์ `config.js` บน GitHub:**
   ```js
   LIFF_ID: "LIFF ID จากขั้นตอน 3.5",
   API_URL: "URL /exec จากขั้นตอน 1.5"
   ```
3. ส่งลิงก์ `https://liff.line.me/<LIFF ID>` เข้ากลุ่มไลน์ครอบครัว

## 5. ใช้งาน

- เปิดครั้งแรก แต่ละคนเลือกชื่อตัวเองครั้งเดียว (Big / Game / Yui / Papa) ระบบจะผูกชื่อนั้นกับบัญชีไลน์
- หลังจากเลือกชื่อแล้ว คนที่ไม่ใช่คนในบ้านจะเลือกชื่อไม่ได้ และจะไม่เห็นตารางจอง
- ถ้ามีคนเลือกชื่อผิด ให้เปิด Google Sheet แท็บ `Members` แล้วลบค่าในช่อง `lineUserId` ของคนนั้น เขาจะเลือกชื่อใหม่ได้
- ตารางในแอปอัปเดตเองทุก 30 วินาที และทุกครั้งที่เปิดแอปกลับมา
- ปักหมุดลิงก์ไว้ในกลุ่มไลน์ หรือใส่ไว้ในโน้ตของกลุ่ม จะได้เปิดง่าย

## เพิ่มทีหลังได้ (ถ้าต้องการ)

ถ้าอยากให้มีบอทส่งข้อความเตือน เช่น "พรุ่งนี้ 07:00 Papa ใช้รถ" ต้องสร้าง **LINE OA** และเปิดใช้ Messaging API เพิ่ม แล้วตั้งเวลาให้ Apps Script ส่งข้อความเตือน
